# Identical C, different instruction selection: the Cortex-M33 build takes
# CMSIS-DSP's ARM_MATH_DSP paths at -O2, the host takes the generic ones at -O1
# under sanitizers. Nothing here is wrong; float32 is simply not associative and
# neither compiler is obliged to order the sums the same way.
#
# What it means for the work this package exists for: a C-versus-Python parity
# suite cannot be bit-exact either. It has to state a tolerance, and 1e-6 on the
# decision is the scale this measurement suggests. Bit-exactness is only ever a
# same-binary, same-target claim - which is exactly what each of these two files
# is used for.
