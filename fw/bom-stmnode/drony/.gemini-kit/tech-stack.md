# Tech Stack - Drone Detection System

## Languages
- **Python:** For data analysis, algorithm prototyping, and training neural networks.
- **C:** For final firmware implementation on STM32H5.

## Hardware
- **MCU:** STM32H5 (ARM Cortex-M33).
- **Sensors:** Digital MEMS microphones (PDM/I2S).

## Libraries & Frameworks
- **DSP:** CMSIS-DSP (C), Librosa / SciPy (Python).
- **AI/ML:** TensorFlow Lite for Microcontrollers (TinyML), STM32Cube.AI.
- **Audio:** Wave module (Python) for initial processing of .wav files.

## Tools
- **IDE:** STM32CubeIDE.
- **Analysis:** Jupyter Notebooks / Python scripts.
