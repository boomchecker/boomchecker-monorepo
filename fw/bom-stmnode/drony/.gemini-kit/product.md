# Product Context - Drone Detection System

## Description
An acoustic system for detecting and identifying drones using MEMS microphones and the STM32H5 MCU.

## Users
- Security forces
- Developers of monitoring systems
- Facility managers requiring protection from unauthorized drones

## Goals
- Real-time detection of drone presence.
- Identification of drone type based on acoustic signature.
- Use of Edge AI for local processing.

## Main Features
- Digital audio collection from MEMS microphones.
- Advanced signal processing (FFT, MFCC).
- Neural network detection (TinyML).
- Low power consumption for field deployment.
