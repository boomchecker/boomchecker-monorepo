# Archive

Selected historical artefacts from the imported thesis source archive.

This is not a full copy of `projects/diplomka_zdrojaky`. The migration intentionally excludes virtual environments, build outputs, vendored ESP-IDF managed components, Python caches, nested `.git` directories, and source snapshots of external tools.

Contents:

- `models/` contains the thesis-era Keras model, TFLite model, and deployable C header.
- `figures/` contains selected generated plots from the original `src` directory.
- `notes/` contains copied source notes where available.

The reproducible workflow lives in the project root, `ml/`, `datasets/`, and `firmware/`.
