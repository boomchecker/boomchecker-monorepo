# Hardware validation

Per-sample capture data from real ESP32-S3 hardware, produced during milestone M6 of
`REPRODUCTION_ROADMAP.md`. Unlike everything under `generated/`, these files cannot be
regenerated by any script — they require a physical board connected over UART. They are
committed here (not gitignored) so they survive `task reproduce:clean` and any environment
reset.

- `esp32s3/esp32_per_sample_{clean,snr30,snr20,snr10,snr5}_test.csv` — one row per held-out
  test-split sample (171 each, seed 42 noise realization), captured by
  `ml/validate_esp_uart.py` against the archived firmware (`archive/models/model_data.h`).
  Columns: `recording_id, variant, split, class_id, score, pred, latency_us`.

Consumed by `ml/make_deliverables.py`'s `load_esp32_comparison_stats()` to fold the
PC-vs-ESP32 per-sample comparison into `generated/reports/reviewer_response.md`. See
`REPRODUCTION_ROADMAP.md` milestone M6 for the full methodology and result.
